\## Description du projet

Ce projet est un mini Pokédex développé en PHP en utilisant la programmation orientée objet (POO).

Il a été réalisé dans le cadre d’un TP visant à mettre en pratique les concepts de classes, objets, PDO, et structuration de projet avec GitHub.
